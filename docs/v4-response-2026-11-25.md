## 二、按报告条目整改

| 报告指出的问题 | 处理 |
| --- | --- |
| methods：`learning rate` 被写成 `3 ×`、`batch size` 混入 `2 actual` | 解析 `3 × 10^-4` 得 `0.0003`；参数值只取逗号/分号前的自属片段；`planned/actual` 要求数字后跟原因或句读 |
| methods：数据集为空、`70/15/15` 划分识别不到 | 新增 release 版本写法（`BRENDA (release 2023.1)`）与 `70/15/15 (…): 2,388 / 512 / 512` 划分规则 |
| methods：hardware 证据跨章节取到 `## Environment` | 材料扫描从句子窗口改为按行扫描；任务说明类文件（`task.md` 等）不再当作正文 |
| kg：两页理论短文抽出 0 节点 / 边为 `kernel -> choice kernel` | 新增理论短语词表与噪声词过滤；单实体边在首个介词处截断、否定句跳过；短文档不再要求词频 ≥2 |
| kg：`PLM`/`PLMs` 未归并、`evaluated on` 关系缺失 | `canon()` 复数去尾阈值 5→4 字符；恢复 `evaluated on` 兜底 |
| kg：缺 `ICSD`/`perovskite` 节点、`trained_on` 未命中 | 补数据库与材料家族词表；`trained on/with/using` 放宽到 40 字符内 |
| nanopub：顶层只有 `assertions`，缺 `nanopubs` | 两个键双写，`assertions` 由每条断言抽出 id/assertion/type/confidence/flags |
| refs：`manuscript_cited.md` 渲染崩（`ValueError: 2 is not in list`） | 排序改用 `sorted(enumerate(...))`，不再对同一 list 调 `index` |
| refs：只用到 `[1]`–`[8]`，`[9]` 从未被引 | 候选扩到 6 条，按来源去重后取 2 条；句中出现大写专名（`BRENDA`/`KEGG`）时加 5.0 分 |
| refs：`reason_for` 与 `rejected_refs` 不可核查 | 改为列出与标题重合的实词与 `fam year`；被拒文献由同句候选生成 |
| polish：`rewrites` 行数少于编辑次数 | 一句多次编辑时每条编辑一行，与 `changes.csv` 对齐 |
| polish：`sentence_issues` 一句多标记只出一行 | 每个 flag 一行 |
| intro：`strength_map.csv` 表头来自别的任务 | 改通用表头 `block,claim,kept_strength,note`，按句命中线索 |
| intro：五段整段是模板拼接（电池实验文本套到酶/晶体题） | 重写为按材料组装：problem/facts/constraints 分节解析，组内逐条带引用与局限，gap 由共同限制推导并标 `derived`，贡献逐条对应 `contribution_map.csv` |
| intro：段落不足 120 词、`contribution_map.csv` 只有 2 行 | 段内补材料自身的限定句（不重复、不编造）；每条事实一行贡献，S08 达 5 行 |
| latex：任务书写明“本机无 TeX”仍报 `attempted: true` | 识别到“未编译/attempted: false”时不编译，并在 `errors` 说明本机实测有 xelatex 可复现 |
| latex：缺图被判 `static_check.ok: false` | 缺图降为 `warnings`；只有仍指向不存在文件的 `\includegraphics` 才算问题 |
| parse：扫描件 `content.blocks` 不为 0、状态仍 `success` | `body_withheld` 贯穿 contract/report/deliver 三处，`blocks` 置空、OCR 文本移到 `content.ocr_blocks` |
| parse：扫描件状态用 `partial` 而契约要 `unable` | 无文字层时状态改为 `unable`（任务书允许，且不暗示解析出了正文） |
